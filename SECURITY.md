# Security Policy

## Scope

This repository contains Markdown, YAML, and validation scripts for a project
workflow. It is not a network service and does not provide access to devices,
accounts, credentials, or production environments.

## Do Not Publish

Please do not submit:

- API keys, passwords, cookies, tokens, or private keys;
- raw conversation exports containing secrets or personal data;
- device identifiers, private network maps, or deployment logs;
- local absolute paths that disclose private environments;
- instructions that bypass the authorization, backup, rollback, or recovery
  boundaries in the Skill.

## Reporting

For a suspected secret or privacy exposure, do not open a public issue with the
material. Contact the repository owner privately and include the affected path,
commit, and a redacted description.
