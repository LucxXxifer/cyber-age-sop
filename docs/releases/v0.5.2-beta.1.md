# v0.5.2-beta.1 — Shared understanding first / 先形成共同理解

Release date / 發布日期：2026-11-05. License / 授權：Apache-2.0.

This public beta promotes the locally tested interaction candidate for real feedback.
It is not a stability certification. The stable release remains
[v0.4.5](https://github.com/LucxXxifer/cyber-age-sop/releases/tag/v0.4.5).

本版依實際使用回饋修正核心互動，供真實小項目試用；不代表完整成熟度已通過。
穩定版仍為 `v0.4.5`，上一測試版 `v0.5.1-beta.1` 保留可下載。

## What changed / 本版變更

- **Confirm before the first Card.** Explore the real use, read back the purpose,
  provisional shape and first-version scope, and obtain substantive owner confirmation.
  Extra facts, a long feature list, silence or Agent confidence are not confirmation.
  There is no fixed number of questioning rounds; applicable prior agreement is reused.
- **Show the idea and action in the conversation.** Useful provisional wireframes or
  flows appear without a separate request. Keep the current action and checks readable
  inline, with engineering detail in the same Brief. Respect a request to skip sketches.
- **Revise and resume against the same agreement.** Entry descriptions cover identifiable
  project clarification, implementation, changes, resumption and alignment checks.
  Read the project entry, agreed record, actual source and evidence at relevant moments.
- **Continue authorized dependent work.** A low-risk local contract may designate
  deterministic checks by the implementer before continuing. Self-checks remain distinct
  from independent review and human acceptance; required separate review still applies.
- **Remove conflicting instructions.** Align templates, visual aids and continuity rules;
  preserve readiness, authorization, verified interfaces, failure handling and provenance.

先釐清想法，透過回述與必要草圖讓使用者修正，只有在使用者實質確認雙方理解一致後，
才生成第一張行動卡。不是問滿幾輪，也不能把補充功能當成確認。
已確認需求可以接續實作、修改及恢復；當前理解與行動直接展示，工程細節留在同一記錄。
低風險依賴可按契約用實際自測放行，仍不能冒稱獨立審查或真人驗收。

## Local evidence and limits / 本機證據與限制

The limited comparison used two small synthetic projects across the previous beta,
candidate and native Agent workflow: six journeys plus three fresh-session recovery
probes, using the same host entry and inherited model configuration. No exact wire-level
model identity, billing or complete tool-event trace was measured.

- All three program implementations passed the same 12 independently rerun black-box
  checks. All three offline plugin cores passed the same four CLI checks.
- All three recovered from existing records without adding features, and respected a
  discussion-only scope change. These capabilities are not unique to the Skill.
- In the plugin's first two turns, the candidate showed provisional sketches and waited
  for confirmation; the previous beta saved a proposal containing a Card before confirmation.
- The candidate's visible replies were longer. This is not evidence of lower reading
  effort, lower token cost, better coding quality or better human understanding.
- One previous-version discussion snapshot was incomplete after a symlink-copy error.
  Copied ordinary source/documents and its prior delivery manifest matched; a complete
  workspace-byte comparison is not claimed for that observation.

本機有限比較中，三組程式各通過同組 12 項檢查，插件資料核心各通過同組 4 項檢查；
三組都能從既有記錄恢復。候選改善了本例的出卡時機，但回覆較長，不能據此宣稱
更會寫程式、小白更容易理解或成本更低。原始試驗資料留在本機，公開內容僅提供摘要。

Human comprehension, implicit host dispatch, actual browser installation, cross-model
reliability and long-running large-project value remain unverified. Explicitly loading
the Skill in a trial does not test automatic discovery. A CLI data core is not a completed
browser extension. Release preparation changes identity and documentation only; the
tested interaction rules are unchanged.

真人理解、自然語義隱式載入、真實瀏覽器、跨模型可靠度及大型項目效益仍待驗證。
本版不提供宿主原生卡片 UI、自適應版面、背景監督、排程器或獨立項目管理平台。
實際執行、搜尋、繪圖及權限仍由所用 Agent／IDE 和模型提供。

## Install and roll back / 安裝與回復

Download **`cyber-age-sop-v0.5.2-beta.1.zip`** from this release and verify it against
`SHA256SUMS.txt`. Install the single `cyber-age-sop/` directory using your host's Skill
mechanism. For local Codex, use `~/.codex/skills/cyber-age-sop/`. Back up the whole old
directory outside the Skill scan path, then replace the whole folder. Avoid overlaying
references from different versions. The Skill will be available on the next turn;
starting a fresh chat is recommended for a clean trial. Invoke `$cyber-age-sop` explicitly.

下載安裝 ZIP 並核對 SHA-256；先完整備份舊目錄，再整個替換。
新版本會在下一輪可用，測試時建議開新 chat 並明確呼叫 `$cyber-age-sop`。
如需回復，以完整舊備份替換；不要混合不同版本檔案。

Assets / 附件：

- `.zip`: installable Skill, including `LICENSE` and `NOTICE` / Skill 安裝包及授權聲明。
- `.tar.gz`: complete public repository snapshot / 完整公開倉庫快照。
- `SHA256SUMS.txt`: SHA-256 checksums for both archives / 兩個附件的校驗值。

The Skill includes no API key, model account or execution service. Installation does
not authorize access to real accounts, deployment or publication.
