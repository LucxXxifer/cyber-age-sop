Release date / 發布日期：2026-10-24. License / 授權：Apache-2.0.

This is a public feedback release, not a stability certification. The stable
release remains [v0.4.5](https://github.com/LucxXxifer/cyber-age-sop/releases/tag/v0.4.5).

這是供實際試用與收集回饋的測試版，不代表已通過完整穩定性驗證。
穩定版仍為 `v0.4.5`。

## What changed / 本版變更

- **Next-Step Card:** one eight-field summary after the project scope is clear, with the current work, inputs, deliverable, non-goals, decisions, permitted actions, evidence and stop condition. Trivial edits skip it.
- **Readable status:** everyday work names; implementation, historical tests and independent acceptance stay separate. Missing records do not establish that work never started.
- **Dependent work:** identify the exact accepted predecessor input; a plan does not authorize every listed task.
- **Basic traceability:** conditional minimum SPEC, task/evidence index, version identity, affected-evidence updates and manual recovery checks in existing project records.
- **Decision provenance:** distinguish human approval, simulation and delegated instructions; a product direction is not product acceptance.

本版整合既有候選的一頁式下一步卡、白話現況、直接依賴、基本追溯與決策來源規則。
目標是讓使用者在同一 Agent／IDE 中，逐步把需求轉成可檢查的規劃與交付。
本地 `0.5.0` 與研究快照屬開發基線；本次沒有補稱為已公開的穩定版本。

## Install / 安裝

Download **`cyber-age-sop-v0.5.1-beta.1.zip`** from this release. Extract the single
`cyber-age-sop/` directory and install it using your Agent/IDE's Skill mechanism.
For local Codex, use `~/.codex/skills/cyber-age-sop/`. Back up an existing install,
replace the whole folder, then start a new session and invoke `$cyber-age-sop`.
The package includes `LICENSE` and `NOTICE`; no API key is included or required
by the Skill itself. Your host supplies model access and tools.

下載上述安裝 ZIP，解壓後按所用 Agent／IDE 的 Skill 安裝方式放入整個目錄。
先備份舊版，再整個替換並開新 session。Skill 不提供模型帳戶、搜尋服務或執行權限。

Assets / 附件：

- `.zip`: installable Skill only, including license notices / 可安裝 Skill 與授權聲明。
- `.tar.gz`: complete public repository snapshot / 完整公開倉庫快照。
- `SHA256SUMS.txt`: SHA-256 checksums for both assets / 兩個附件的校驗值。

To roll back, replace the whole installed folder with the stable release's
`skills/cyber-age-sop/` folder. Do not overlay files from different versions.
退回穩定版時同樣以整個目錄替換，避免混入測試版 references。

## What is known / 已知證據與限制

Structural validation covers package contents, frontmatter, fences and release
integrity. Limited local pilots informed the candidate; they do not prove novice
comprehension, end-to-end autonomous delivery or long-term large-project value.
The paired local engineering pilot used predefined requirements, SPEC and tasks;
its success does not show that the Skill independently discovers them correctly.
No new model experiments were run for this release.

Model output can still be wrong despite the instructions. Observed risks include
inferring a stage from missing test/acceptance records, repetitive explanations
and incomplete reviewer rationales. Source-checked examples exist for Astra/max;
DeepSeek/xhigh has both useful outputs and recorded content/reviewer failures.
These observations are not a universal model ranking or a runtime guarantee.
Full dual-route workflow validation remains incomplete.

結構檢查只證明安裝包符合已檢查的結構，不代表小白已看懂或能自主交付。
既有工程試點預先提供需求、SPEC 和任務，不能當作完整需求引導已驗證。
模型仍可能過度推論現況、重複說明或核對不完整；不同模型／宿主的表現會不同。
本次發布沒有重跑模型實驗，完整雙路由工作流與長期大型專案效益仍未驗證。

No adaptive Card layout, autonomous scheduler, separate Project State system,
automatic cross-session execution or built-in domain engine is included.
The lifecycle reference guides manual continuity checks; it does not execute them
as a background service. Deployment, publication and external account operations
still require the applicable authorization and host capabilities.

本版沒有自適應卡片、自動排程器、獨立 Project State 系統或背景續做服務。
它提供流程約束與按需核對，不是項目管理平台或整套解決方案。
