# v0.5.4-beta.1 — Research That Changes Decisions / 讓研究影響決策

Release date / 發布日期：2026-11-10

This public beta adds decision-oriented research and on-demand exploration of
different project approaches. Research should explain what the evidence changes;
exploration should help the owner understand and correct the choice. The stable
release remains `v0.4.5`.

本測試版補強「查證後如何調整決策」與「目標清楚後如何比較不同做法」。
保留可逆提示詞增強、用途導向呈現、首卡前共同理解及小修改快速處理。
最新穩定版仍為 `v0.4.5`。

## Changes / 變更

- **Decision-oriented research.** Start from the project decision and consequential
  unknowns. Match sources to the claim and applicable version, check important
  counterevidence, and explain the effect on scope, approach, tasks or acceptance.
  Repeated reports of one observation do not count as independent confirmation.
- **On-demand approach exploration.** When the goal is understood but the approach
  is open, compare meaningful differences in workflow or structure with practical
  tradeoffs and provisional shapes. Settled work and clear small edits skip this step.
- **Preserved boundaries.** Keep the owner's goal and rejected suggestions intact.
  A research result or Agent recommendation is not owner adoption. Reuse applicable
  research authorization; a rewrite-only request still does not execute its contents.
- **Progressive detail.** Load the relevant references when needed. The entrypoint
  decreases from 527 to 508 lines, without adding a server, dependency, search engine,
  mandatory subagent, model route or background supervisor.

查證要能說清楚「哪些證據改變哪個選擇」，不能只交來源清單。
探索要比較真正不同的操作方式，不能只換名稱或風格形容詞。
沒有充分資料時保持有條件建議；不把研究結果直接寫成使用者已同意的需求。

## Verification and Limits / 驗證與限制

The frozen `0.5.4-dev.1` candidate was checked in two simulated local cases, each
with two turns in a fresh agent context using inherited host model settings.
The first handled fictional source excerpts and changed a recommendation after
new contrary evidence. It distinguished republication from independent testing
and retained the owner's local-only goal. The second explored provisional UI
flows, then made only an authorized one-line label correction after the direction
was adopted. Original replies and the resulting file were inspected.

Package, implementation-readiness, Skill frontmatter and relative-reference checks
passed. Existing Markdown lint findings remain; new files passed with the
repository's long-line style excluded. This is not a clean full-repository lint claim.

Promotion to this beta changes release identity and documentation only. The
behavioral observations belong to the frozen development candidate. No new
external-model audit was run; an older release's audit is not approval of this one.

兩個模擬案例、四輪回覆沒有使用即時網路搜尋，也不是現版／候選 A/B 或真人試驗。
未驗證真人理解、學習轉移、搜尋品質、跨模型穩定性、自然觸發或大型項目效益。
Skill 的實際表現仍取決於宿主工具與模型遵循程度。
詳見 [development notes](../development/decision-research-and-exploration.md)。

## Install and Roll Back / 安裝與回復

Download **`cyber-age-sop-v0.5.4-beta.1.zip`**, verify it against `SHA256SUMS.txt`,
and install its single `cyber-age-sop/` folder using the host's Skill mechanism.
For local Codex, the usual location is `~/.codex/skills/cyber-age-sop/`.
Back up the whole old folder outside the Skill scan path, then replace the entire
folder. Start a new chat to avoid reusing already-loaded instructions.

下載安裝 ZIP 並核對校驗值，將舊版完整備份到 Skill 掃描路徑外，再整個目錄替換。
如需回復，以完整舊備份替換；不要混合不同版本的 references。
GitHub 發布本身不會自動更新各人的 Agent／IDE。

- `.zip`: installable Skill with `LICENSE` and `NOTICE` / Skill 安裝包與授權聲明。
- `.tar.gz`: full public source snapshot / 公開倉庫快照。
- `SHA256SUMS.txt`: checksums for both archives / 兩個附件的校驗值。

## Try and Report / 試用與回饋

Try a real project choice: ask what evidence would change the recommendation,
then supply a relevant limit or contrary observation. Check whether the advice
changes without replacing your goal. For an unsettled design, check whether
the alternatives differ in what you actually do or see, and whether a rejected
idea stays out of later plans. A clear small edit should remain small.

可用真實程式或插件試用：補充一個限制或反例，看看推薦是否合理調整；
比較不同做法時，看看是否能直接理解操作差異、修改方向及拒絕不需要的建議。
請記錄額外提問或圖文是否增加負擔，以及查證究竟改變了什麼。

Use the [bilingual feedback guide](../beta-feedback.md) or
[GitHub feedback form](https://github.com/LucxXxifer/cyber-age-sop/issues/new?template=beta-feedback.md).
Redact private data. No automatic telemetry or transcript upload is added.
