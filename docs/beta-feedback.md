# Beta feedback / 測試版回饋

Current beta / 目前測試版：`v0.5.2-beta.1`（2026-11-05）。Record the exact installed version and host. / 請記下實際安裝版本與宿主。

We want to learn whether Cyber-Age SOP helps you turn an idea into a clear,
bounded project and a usable result. You do not need to diagnose technical causes.
There is no automatic telemetry or transcript upload in the Skill.

我們想知道它能否幫你說清楚想法、控制範圍，並逐步得到能用的成果。
不必懂技術原因；安裝 Skill 不會自動回傳使用紀錄。

## Try it / 怎樣試

1. Choose a small real tool, program, plugin or Skill you want. Use local or mock data initially.
2. Describe the goal in your own words; say when you do not understand a question or output.
3. Check whether a useful provisional sketch appears in the conversation. Correct the Agent's understanding; confirm only when the purpose and first-version scope match what you mean. The first action Card should follow that confirmation.
4. If you continue to implementation, check the actual result and failure cases. Try a revision or resume from the saved project record when relevant. A plan-only trial is also useful; label where you stopped.

先選一個真實、規模小的項目，使用本機或模擬資料。用自己的話說目標，看不懂就直接說。
觀察必要草圖是否主動在對話出現；若理解不同就修正，真正覺得用途與第一版範圍一致後再確認，第一張卡應在此後出現。
可以只試規劃，也可以做到實作、修改或續做；回饋請寫明停在哪一階段。

## What to send / 回饋什麼

Use the [GitHub feedback form](https://github.com/LucxXxifer/cyber-age-sop/issues/new?template=beta-feedback.md),
or give the following short record to the person who invited you. GitHub issues
are public. Share only excerpts you are allowed to disclose; no complete transcript is required.

可以用 GitHub 表格，或直接交給邀請你試用的人。GitHub issue 是公開的，無需貼整份對話。

```text
Skill version / Skill 版本：
Agent or IDE and version / 使用工具與版本：
Model and effort (if known) / 模型與推理設定（知道才填）：
Programming experience / 程式經驗：
What I wanted to make / 我想做什麼：
Where I stopped / 做到哪個階段：
What helped / 有幫助的地方：
Confusing or wrong excerpt / 看不懂或錯誤的原句：
What I expected and observed / 預期與實際結果：
Did the Agent explore and read back before I confirmed? / 是否先探索與回述，再由我確認：
Did a useful sketch appear without a separate request? / 必要草圖是否主動在對話顯示：
When did the first Card appear? / 第一張卡出現時，我是否已確認共同理解：
Was the action visible inline? / 不開附件能否明白現在做什麼：
Could a revision or new session reuse the agreed record? / 修改或新會話能否沿用確認稿：
Could I identify the next step? / 我能否知道下一步：
Could I check completion? / 我能否確認做完了：
Extra explanations, repeated questions or paperwork / 額外解釋、重問或文書負擔：
Approximate time (optional) / 大約耗時（選填）：
```

An incomplete or unsuccessful trial is useful evidence too. Do not invent an
answer for fields you did not observe. A confusing explanation is a product issue
to investigate, not a test of the reader's intelligence.

未完成或失敗也有價值；未觀察到的欄位可以留空。看不懂是我們要改善的問題，並非測試你的能力。

## Privacy / 隱私

Remove credentials, cookies, personal or customer data, internal URLs, proprietary
code and identifying screenshots. Use a minimal redacted example. Report security
issues through [SECURITY.md](../SECURITY.md) instead of a public feedback issue.

請移除憑證、cookie、個資、客戶資料、內網網址、公司程式碼和可識別畫面。
安全漏洞請依 [SECURITY.md](../SECURITY.md)處理，不要直接公開敏感細節。
